# ROI Calculator

Framework to quantify the value of Qtangl vs the status quo (spreadsheet/consulting) for a prospect. Use directionally in deals and as a web tool input ([05-content-and-seo.md](../05-content-and-seo.md) lead magnet).

**Honesty note:** Present as an estimate with the prospect's own inputs; never overstate. Avoid breach-cost fear-math as the headline.

---

## Value drivers

| Driver | How Qtangl creates value |
|--------|--------------------------|
| Time to inventory | Minutes vs weeks (internal) or 6+ weeks (consulting) |
| Labor avoided | No manual spreadsheet build/maintenance |
| Consulting offset | Replace/augment a baseline inventory engagement |
| Continuous monitoring | Catch drift without re-engaging consultants each cycle |
| Audit prep | Reusable signed evidence vs ad hoc evidence gathering |
| Risk reduction | Earlier detection of quantum-vulnerable + expiring certs |

---

## Inputs (prospect-provided)

| Input | Example |
|-------|---------|
| Internal hours for manual inventory | 200 hrs |
| Loaded hourly cost | $120/hr |
| Inventory refresh frequency | Quarterly |
| Consulting baseline quote (if any) | $150,000 |
| Audit cycles per year | 2 |
| Hours per audit on crypto evidence | 40 hrs |

---

## Sample calculation (illustrative)

### Status quo annual cost

| Item | Calc | Cost |
|------|------|------|
| Manual inventory (4×/yr) | 200 hrs × $120 × 4 | $96,000 |
| Audit evidence prep (2×/yr) | 40 hrs × $120 × 2 | $9,600 |
| Consulting baseline (amortized) | $150,000 / 3 yr | $50,000 |
| **Status-quo total** | | **~$155,600/yr** |

### With Qtangl Monitor

| Item | Cost |
|------|------|
| Monitor subscription (mid) | $100,000/yr |
| Internal oversight (light) | ~$10,000/yr |
| **Qtangl total** | **~$110,000/yr** |

### Outcome

| Metric | Value |
|--------|-------|
| Gross annual saving | ~$45,600 |
| Plus: continuous drift coverage | Not in status quo |
| Plus: reusable signed evidence | Reduces audit friction |
| Plus: faster board reporting | Qualitative |

**Framing:** "Comparable or lower cost than a one-time consulting inventory — but living, continuous, and auditable."
