# Outreach kit

## Goal

Use the hospital re-staffing demo to book short discovery calls with operations leaders at 300-600 bed hospitals.

## Recommended sequence

1. Personalize one sentence per recipient with a recent staffing, agency-spend, or throughput signal.
2. Send no more than 25 emails per day from a warmed domain.
3. Include the 60-second walkthrough in the first outreach and the 3.5-minute demo only after reply.
4. Attach the leave-behind PDF after a positive response or after a live demo.

## Primary assets

- `cold_email.md`
- `linkedin_dm.md`
- `leave_behind.md`
- `leave_behind.pdf`
- `target_hospitals.csv`

## Rules

- Do not promise that the hybrid path is faster than the classical path.
- Lead with auditable alternatives, reduced agency reliance, and staffing-office decision support.
- Only send PHI-free examples and only request anonymized roster CSVs.
