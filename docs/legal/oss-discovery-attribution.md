# OSS discovery engine attribution

Qtangl code/binary discovery orchestrates the following open-source tools:

| Engine | Purpose | License |
|--------|---------|---------|
| CryptoScan (CSNP) | Source code cryptographic discovery | See upstream repository |
| CryptoDeps (CSNP) | Dependency reachability analysis | See upstream repository |
| CBOMkit-theia | Container/binary filesystem scan | Apache-2.0 |

Engines run as isolated subprocesses; Qtangl normalizes output into CycloneDX CBOM with provenance tags.
