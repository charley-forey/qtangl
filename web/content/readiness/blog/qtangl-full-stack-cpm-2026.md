Qtangl now delivers **full-stack cryptographic posture management (CPM)** across agentless external scan, host sensor fleet, source code scan, and container/binary CBOM — with the same signed evidence layer auditors already verify on Assess and Monitor.

## What changed

- **Host sensor:** mTLS enrollment, daemon heartbeat, NSS/Java store coverage, offline signed bundles
- **Code scan:** Git clone + CryptoScan + CryptoDeps in the discovery worker; SARIF in CI
- **Binary scan:** Registry credential pull and bom-ref level source/runtime diff in reports
- **Enterprise evidence:** 10k soak harness, discovery SLO dashboards, SOC2 sensor control pack

Public matrix claims use **internally validated at scale** until the 500+ agent customer pilot case study publishes.
