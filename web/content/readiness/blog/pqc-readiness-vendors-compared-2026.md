## The category in one sentence

**Post-quantum readiness** (also **crypto-agility**, **CPM**) means inventorying quantum-vulnerable cryptography, monitoring drift, and proving remediation before Q-Day — with **CycloneDX CBOM** as the standard artifact.

## Tier A — Direct PQC platforms

| Vendor | Primary discovery | Qtangl wins when |
|--------|-------------------|------------------|
| [SandboxAQ](/compare/qtangl-vs-sandboxaq) | Host agents / sensors | Mid-market speed + public verify |
| [Keyfactor](/compare/qtangl-vs-keyfactor) | Host agents + CLM | Agentless external baseline |
| [QuSecure](/compare/qtangl-vs-qusecure) | Network overlay + R3 Recon | Assessment before overlay |
| [IBM Quantum Safe](/compare/qtangl-vs-ibm-quantum-safe) | Code scan + runtime | External baseline this week |
| [Fortanix](/compare/qtangl-vs-fortanix) | KMS/HSM keys | TLS/JWKS/SSH + Mosca HNDL |
| [Palo Alto](/compare/qtangl-vs-palo-alto) | NGFW telemetry | Standalone portable evidence |

## Tier B — Pure-play twins

[Qinsight](/compare/qtangl-vs-qinsight), [ExeQuantum](/compare/qtangl-vs-exequantum), and [Encryption Consulting](/compare/qtangl-vs-encryption-consulting) all ship fast inventory + CBOM. **That core is now table stakes.** Qtangl wins on **signed public verify** and mid-market packaging.

## What actually differentiates

1. **Signed + publicly verifiable evidence** — Qtangl is the only vendor in our matrix marked Yes for independent offline verification.
2. **Mid-market self-serve** — transparent pricing, minutes-to-inventory.
3. **Honest scope** — agentless external baseline; layer onto incumbents for depth.
